# Skybound Scout

A tiny browser 2D platformer. Run, jump, collect coins, stomp Bramble Bugs, and light the summit beacon.

## How to run

From this folder:

```bash
python3 -m http.server 8080
```

Open [http://127.0.0.1:8080/](http://127.0.0.1:8080/).

Or serve the repo root and open `/games/platformer/`.

## Controls

| Action | Keys | Touch |
| --- | --- | --- |
| Move | ← → / A D | On-screen arrows |
| Jump | Space / W / ↑ | Jump button |
| Restart | R | Overlay button |

## Goal

Collect coins, avoid or stomp Bramble Bugs, reach the glowing beacon. You have 3 lives.
